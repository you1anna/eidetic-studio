# Roland TB-03 — quick reference

**Role in the rig:** acid bass synth, end of the MIDI chain, sequenced by the Octatrack on **channel 2**. Roland Boutique — **3.5 mm mini stereo output** (not ¼″), broken out to the patchbay → Soundcraft Ch 2 (dbx-limiter channel).
**Menu access:** system settings = hold `[FUNCTION]` + turn `[VALUE]` to pick the parameter, release `[FUNCTION]`, set with `[VALUE]`, press `[FUNCTION]` to exit. **Settings persist automatically** (no WRITE step).

> Cross-refs: clock/sync → [`../guides/midi-sync.md`](../guides/midi-sync.md) §5 · wiring → [`../knowledge-base.md`](../knowledge-base.md) §0.2/§9.

## How do I… (task → exact steps)

| Task | Steps | Source |
|---|---|---|
| **Lock it to the DIN clock (not USB)** | Hold `[FUNCTION]`+`[VALUE]` → **MIDI Clock Source (`SYnC`) = `NiDi`** (MIDI). Default `AutO` gives USB priority over DIN. | midi-sync §5 |
| **Match the Octatrack's sequencing channel** | `[FUNCTION]`+`[VALUE]` → **MIDI Channel (`CH`) = 2** (must equal the OT MIDI track's CHAN). | midi-sync §5 |
| **Stop it powering off mid-session** | `[FUNCTION]`+`[VALUE]` → **Auto Off (`A.OFF`) = OFF** (default powers down after 30 min — looks exactly like a sync failure). | midi-sync §5 |
| **Run it under external clock** | No transport-receive toggle exists — put the `[MODE]` knob in **PATTERN PLAY** (or TRACK PLAY), select the pattern; it chases the OT's start/stop and tempo automatically. | midi-sync §5 |
| **Let the OT play its notes without layering** | When the OT sequences it note-by-note, clear/empty the TB-03's own pattern so the two don't stack. | midi-sync §2/§5 |

## Known gotchas

- **3.5 mm mini output**, not ¼″ TS — uses a mini→dual ¼″ TRS breakout to the patchbay (KB §9).
- `SYnC` and `CH` display as `NiDi` / numeric on the tiny screen — easy to misread.
- Nothing is cabled to its MIDI OUT, so its own Soft Thru (`thrv`) is irrelevant — leave default.
